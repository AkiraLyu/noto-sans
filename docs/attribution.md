# 来源

Noto Sans Akira 1.000 使用以下字体资源：

- Noto Sans CJK SC 2.004：西文字母、数字、ASCII 标点、比例弯引号、中点及其他已有字形。原始版权为 © 2014–2021 Adobe。
- Noto Sans 2.015：部分西文符号、数学符号及空格。原始版权为 Copyright 2022 The Noto Project Authors。

Noto Sans CJK SC 的字母轮廓、字重、字距调整、连字和组合附加符号相关特性被保留。汉字和东亚排版特性不包含在衍生字体中。

Regular、Thin、Light、Medium、Bold、Black 的补充符号使用 Noto Sans 对应字重。DemiLight 的补充符号在轮廓结构一致时由 Light 与 Regular 等比例插值；少量轮廓结构不同的符号采用 Light。补充字形的二次曲线被转换为 CFF 三次曲线。补充字形不包含原 TrueType 指令。

- [Noto Latin、Greek、Cyrillic](https://github.com/notofonts/latin-greek-cyrillic)
